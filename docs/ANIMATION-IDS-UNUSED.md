# Unused R15 animation ids (Tactical Combat pack)

Converted from the BZ1 Studios Tactical Combat pack (R6) to R15 and published on 5 Nov 2026.
Owner: the Last Light group (964368511). All are approved and active.

These are the clips the shooter does not use yet. In use: upper-body cuts (legs and hips removed, so the walk keeps
the legs) of the AKM set (AK), the Beretta 92 set (Pistol) and the Shotgun set (Shotgun), listed in
src/campaign/ReplicatedStorage/Shared/PackAnims.luau. The full-body versions of those sets are listed at the end of
this file. Every full-body id is also in horror-shooter/anims/AnimationIds.luau.
Each clip animates the pack gun parts by name (Handle, RootPart, Bolt, Mag...), so a clip only looks right with
the matching pack gun model attached to the right hand.

77 unused full-body clips from the other sets, plus the full-body AKM, Beretta 92 and Shotgun sets (20)
and three upper-body cuts not wired in (end of file).
